# MF-no.1：note × X 運用リポジトリ

note（GASツールの販売）と X の発信をまとめて管理するためのリポジトリです。

- `gas/`：スプレッドシートで動く「note×X 投稿管理ツール」（Google Apps Script）
- `articles/`：note 記事の原稿（公開済み・下書き）
- `docs/`：運用方針（X の運用計画など）
- `tests/`：GAS のうち、シートに依存しない部分のテスト

> **このリポジトリは公開（public）です。** 有料記事の有料エリア・完全版コード・顧問先や勤務先の情報・APIキーは置かないでください。置きたい場合は先にリポジトリを非公開にしてください。

---

## note×X 投稿管理ツール

noteの記事をもとに、Claude が X の投稿案を作り、スプレッドシートで推敲から予約まで管理します。
**X への投稿は自分で行います**（X の予約投稿機能を使用）。noteにもXにも自動ログイン・自動投稿はしないので、規約上のリスクはありません。

```
「記事」シートに記事を登録（タイトル・URL・本文の要点）
   ↓ 行を選択してメニュー「選択した記事からX投稿案を作成」
「X投稿」シートに投稿案が追加される（文字数・NGワードを自動チェック）
   ↓ 自分の言葉に直す（直すとチェックが自動で更新される）
X で予約投稿 → ステータスを「予約済」にして日時を入れる
   ↓ 毎朝、今後7日間の予定が目標本数より少なければメールで通知
```

### シート構成

| シート | 役割 |
|---|---|
| 設定 | モデル、文体、ハッシュタグ方針、NGワード、週の目標本数など。**コードを触らずにここで変更** |
| 記事 | note 記事の一覧。「本文・要点」に無料部分や要点を貼る |
| X投稿 | 投稿案と運用記録（柱・型・本文・リンク・文字数・チェック・ステータス・予定日時・反応） |

ステータスは `案 → 推敲済 → 予約済 → 投稿済`（使わない案は `見送り`）。

### 導入手順

1. 新しい Google スプレッドシートを作成し、「拡張機能」→「Apps Script」を開く
2. `gas/` の各 `.gs` ファイルを同じ名前で作成して中身を貼り付ける
3. エディタ左の「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」をオンにし、`gas/appsscript.json` の内容で置き換える
4. 保存してスプレッドシートを再読み込みすると、メニューに「note×X」が出る
5. 「① 初期設定（シート作成）」を実行（初回は権限の承認画面が出ます）
6. 「② APIキーを設定」を実行し、Anthropic Console で発行した API キーを貼る
   - キーはスクリプトプロパティに保存され、シートやコードには残りません
7. 「記事」シートに記事を1行入れ、その行を選択して「選択した記事からX投稿案を作成」

`clasp` を使う場合は、`gas/` を rootDir にしてください（`.clasp.json` はコミットしない設定にしています）。

### 費用の目安

Claude API の従量課金です。初期設定のモデル `claude-opus-5-5`（effort: low）で、1記事から3案を作ると1回あたり数円〜10円程度の想定です。実際の使用量は Apps Script の「実行数」ログ（`Claude usage:` の行）と Anthropic Console で確認できます。

### 権限について

`appsscript.json` で必要な権限だけに絞っています。

| 権限 | 用途 |
|---|---|
| このスプレッドシートのみ編集 | シートの読み書き |
| 外部サービスへの接続 | Claude API の呼び出し |
| メール送信 | リマインド通知 |
| トリガーの管理 | 毎朝のリマインド |
| メニュー・ダイアログ表示 | 専用メニュー、APIキーの入力 |
| メールアドレスの取得 | リマインドの送信先 |

### テスト

```bash
node tests/run-tests.js
```

文字数カウント、チェック、API リクエストの組み立て、応答の読み取り、再試行、シート行への変換を確認します。API には接続しません。
