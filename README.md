# MF-no.1：note × X 運用リポジトリ

note（GASツールの販売）と X の発信をまとめて管理するためのリポジトリです。

- `gas/`：スプレッドシートで動く「note×X 投稿管理ツール」（Google Apps Script）
- `articles/`：note 記事の原稿（公開済み・下書き）
- `docs/`：運用方針（X の運用計画など）
- `tests/`：GAS のうち、シートに依存しない部分のテスト

> **このリポジトリは公開（public）です。** 有料記事の有料エリア・完全版コード・顧問先や勤務先の情報・APIキーは置かないでください。置きたい場合は先にリポジトリを非公開にしてください。

---

## note×X 投稿管理ツール

過去に作ったGASを貼るだけで、Claude が note 記事の下書きと X の投稿案を作り、スプレッドシートで公開・予約まで管理します。
**note と X への投稿は自分で行います**。どちらにも自動ログイン・自動投稿はしないので、規約上のリスクはありません（noteは公式RSSを読むだけ）。

```
「ネタ帳」に過去のGASを貼る（＋ひとことメモ）
   ↓ メニュー「ネタ帳：選択したコードから記事の下書きを作成」
   ↓ 送信前チェック（メールアドレス・ファイルID・APIキー・法人名などがあれば止まる）
Googleドキュメントに記事の下書き（無料エリア＋有料エリア、価格案、タイトル案）ができ、「記事」シートに登録される
   ↓ 【要確認】を埋めて推敲し、完全版コードを貼って note で公開（手動）
毎朝の自動処理：noteのRSSから公開を検知 → 記事にURLを紐づけ → X投稿案を「X投稿」シートに作成
   ↓ 推敲して X で予約投稿（手動）→ ステータスを「予約済」に
毎朝、今後7日間の予定が目標本数より少なければメールで通知
```

### シート構成

| シート | 役割 |
|---|---|
| 設定 | モデル、文体、ハッシュタグ方針、NGワード、週の目標本数、noteのRSS など。**コードを触らずにここで変更** |
| ネタ帳 | 記事にしたい過去のGASを貼る場所。1行＝1記事 |
| 記事 | note 記事の一覧。下書き作成時とRSS取り込み時に自動で行が追加される |
| X投稿 | 投稿案と運用記録（柱・型・本文・リンク・文字数・チェック・ステータス・予定日時・反応） |

ステータスは `案 → 推敲済 → 予約済 → 投稿済`（使わない案は `見送り`）。

### 導入手順

1. 新しい Google スプレッドシートを作成し、「拡張機能」→「Apps Script」を開く
2. `gas/` の各 `.gs` ファイルを同じ名前で作成して中身を貼り付ける
3. エディタ左の「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」をオンにし、`gas/appsscript.json` の内容で置き換える
4. 保存してスプレッドシートを再読み込みすると、メニューに「note×X」が出る
5. 「① 初期設定（シート作成）」を実行（初回は権限の承認画面が出ます）
6. 「② APIキーを設定」を実行し、Anthropic Console（https://platform.claude.com）で発行した API キーを貼る
   - キーはスクリプトプロパティに保存され、シートやコードには残りません
7. 「設定」シートの「noteのRSS」に `https://note.com/あなたのID/rss` を入れ、メニュー「noteの新着記事を取り込む」を一度実行（公開済み記事がまとめて入ります）
8. メニュー「毎朝の自動処理を有効にする」を実行
9. 「ネタ帳」の「コード」列に過去のGASを貼り、その行を選択して「ネタ帳：選択したコードから記事の下書きを作成」

`appsscript.json` を貼らなかった場合は、エディタ左の「サービス」の＋から「Drive API」（v3）を追加してください（下書きドキュメントの作成に使います）。

### 運用のコツ
- 下書きのタイトルを note で変えて公開した場合は、「記事」シートのタイトルも同じに直すか、URL を手で貼ってください（タイトルが一致すると自動で紐づきます）。
- 記事の生成は「構成 → 無料エリア → 有料エリア」の3回に分けて Claude を呼びます（GAS の通信は1回約60秒で打ち切られるため）。時間切れになる場合は「設定」の `effort（記事）` を low のまま再実行するか、モデルを `claude-sonnet-5-5` に変えてください。
- 「記事のお手本（任意）」に過去の記事本文を1本貼ると、下書きの語り口がそれに近づきます。

`clasp` を使う場合は、`gas/` を rootDir にしてください（`.clasp.json` はコミットしない設定にしています）。

### 費用の目安

Claude API の従量課金です。初期設定のモデル `claude-opus-5-5`（effort: low）で、X投稿案（1記事3案）は1回あたり数円〜10円程度、記事の下書きは1本あたり数十円程度の想定です。実際の使用量は Apps Script の「実行数」ログ（`Claude usage:` の行）と Anthropic Console で確認できます。

### 権限について

`appsscript.json` で必要な権限だけに絞っています。

| 権限 | 用途 |
|---|---|
| このスプレッドシートのみ編集 | シートの読み書き |
| このツールが作ったファイルのみ | 記事の下書きドキュメントの作成（ほかのドライブのファイルには触れません） |
| 外部サービスへの接続 | Claude API の呼び出し、noteのRSSの読み込み |
| メール送信 | 毎朝の通知 |
| トリガーの管理 | 毎朝の自動処理 |
| メニュー・ダイアログ表示 | 専用メニュー、APIキーの入力 |
| メールアドレスの取得 | リマインドの送信先 |

### テスト

```bash
node tests/run-tests.js
```

文字数カウント、チェック、送信前チェック、Markdown→HTML 変換、記事用プロンプト、API リクエストの組み立て、応答の読み取り、再試行・時間切れ、シート行への変換を確認します。API には接続しません。
