# X 運用方針

## 方針
「税理士事務所の職員が、GAS と AI で実務を楽にしていく記録」として発信する。AI の勉強そのものも投稿ネタにする。

## 発信の柱

| 柱 | 内容 | 割合 |
|---|---|---|
| GAS実例 | Before/After を短い画面録画・GIF で見せる。note への主な入口 | 40% |
| AI検証 | 実務で AI を試した結果（ダミーデータで検証） | 30% |
| 制度・季節 | 電子帳簿保存法、インボイス、年末調整、確定申告。11〜3月は特に重視 | 20% |
| 人柄 | スノーボード、資格勉強の進み具合 | 10% |

顧問先のデータは AI に入れない。「事務所で AI を使うときの線引き」自体も投稿ネタにする。

## 運用（週1時間30分）
- 日曜60分：「X投稿」シートで1週間分（3〜4本）を推敲 → X の予約投稿で予約 → ステータスを「予約済」に
- 平日5分：返信対応、同業の投稿に1〜2件コメント
- 投稿後：反応（インプレッション・いいね・リンククリック）をシートに記録

## 導線
X（Before/After・AI検証）→ プロフィール・固定ポスト → note 無料記事・無料コード → 有料記事／事務所向け版／導入代行

プロフィール案：
> 税理士事務所で会計監査｜GAS×AIで経理の手作業を減らす仕組みを作っています｜マネーフォワード形式のツールをnoteで配布｜行政書士・社労士・簿記を勉強中🏂

固定ポスト：出納帳記事の Before/After 動画 ＋ note へのリンク（記事のコード修正後）。

## AI 学習ロードマップ（作るもの＝投稿ネタ）

| 月 | 作るもの | 学ぶこと |
|---|---|---|
| 1 | 投稿管理シート＋GAS から Claude API で投稿案を作成（このリポジトリの `gas/`） | API の基本、プロンプト、キーの安全な管理 |
| 2 | 構造化出力の活用、生成文の自動チェック強化（税務的な誤りの検出など） | 出力の検証・評価 |
| 3 | クレカ明細を AI で科目分類 → MF 取込用 CSV（ダミーデータで精度測定） | 実務への組み込み、AI とルールの使い分け |

## 3か月の目安
- フォロワー300〜500（会計・経理界隈）
- X → note の流入 月100件以上
- 有料記事の販売または導入代行の相談が月数件
- 2か月目に販売5本または相談1件がなければ題材を見直す
